# 受け入れ基準

本書は今後の実装の完了条件を定義する。チェック欄は実装後に検証するためのものであり、現時点での動作確認結果ではない。
対応する仕様に変更があった場合は、本書も更新する。

## 1. 設定・開始

- [ ] AC-01：初回表示が設定画面で、制限時間 60 秒・出題文字数 8 文字が選択されている。
- [ ] AC-02：時間を 30・60・120 秒、文字数を 5・8・12 文字から選べる。
- [ ] AC-03：開始後に 3 → 2 → 1 が各 1 秒表示され、その後に初問の表示と制限時間の計測が同時に始まる。
- [ ] AC-04：開始操作を連打してもゲームが一つだけ始まり、カウントダウン中のキーは成績や回答に持ち越されない。

参照：[画面仕様](screens.md)、[ゲーム仕様](game-rules.md)。

## 2. 出題

- [ ] AC-05：すべての問題が選択した 5・8・12 文字になり、ローマ字入力仕様の 71 文字以外を含まない。
- [ ] AC-06：問題生成が各文字を等しい確率で独立に抽選し、単語辞書を使用しない。固定した乱数源で確認でき、同一文字の連続・前問と同一の問題も拒否しない。
- [ ] AC-07：最後のキーで問題が完了し、待機や追加操作なしで次問に進む。そのキーが次問へ二重に適用されない。

参照：[ゲーム仕様](game-rules.md)、[ローマ字入力仕様](romanization.md)。

## 3. 正誤判定

次の短い問題例は、判定処理を個別に検証するための固定データである。画面の出題文字数の選択肢を増やすものではない。

- [ ] AC-08：対応表にある全 71 文字を、定義された各表記で入力できる。
- [ ] AC-09：「し」の `shi`・`si`、「ち」の `chi`・`ti`、「つ」の `tsu`・`tu`、「ふ」の `fu`・`hu`、「じ」の `ji`・`zi` をそれぞれ受け付ける。ガイドも入力に追従する。
- [ ] AC-10：「んか」に `nka`・`nnka`・`n'ka` を受け付ける。最初の `n` の後で候補を一つに固定しない。
- [ ] AC-11：「んあ」に `nna`・`n'a`、「んや」に `nnya`・`n'ya` を受け付け、`na`・`nya` では完了しない。
- [ ] AC-12：「かん」は `kan` だけでは完了せず、`kann`・`kan'` で完了する。「んな」に `nna`・`nnna` を受け付ける。「んん」は `nnn` では完了せず、`nnnn`・`nnn'`・`n'nn`・`n'n'` で完了する。
- [ ] AC-13：「し」で `s` → `x` → `i` と入力すると、正しいキー 2・ミス 1 で完了する。`x` の時点では進捗を失わず、ガイドも正しい経路を維持する。
- [ ] AC-14：大文字の `SHI` と小文字の `shi` が同じ結果となる。数字・空白・Backspace・Delete・修飾キー・貼り付け・キーリピートは正しいキーにもミスにも数えない。
- [ ] AC-15：IME 変換中の入力と全角文字を回答に数えず、IME 変換開始を検出した場合は半角英数の案内を出す。
- [ ] AC-16：同じ問題を短い表記・長い表記で完了すると、それぞれ実際に受理したキー数を記録する。

参照：[ローマ字入力仕様](romanization.md)。

## 4. 時間と終了

- [ ] AC-17：カウントダウンを制限時間に含めず、画面更新の回数に依存せずに時間を測る。
- [ ] AC-18：期限直前の有効なキーを数え、期限ちょうど以降のキーを数えない。遅れたタイマー処理や無入力の場合も終了する。
- [ ] AC-19：タブ移動・フォーカス移動で時間が止まらず、期限後に戻ると結果画面になる。
- [ ] AC-20：時間切れで結果が一度だけ確定し、終了後のキーや前回のタイマーで結果が変わらない。
- [ ] AC-21：入力途中の問題のキー数・ミス数を成績に含め、完了問題数には加えない。

参照：[ゲーム仕様](game-rules.md)、[構成・データ設計](architecture.md)。

## 5. 成績・繰り返し

- [ ] AC-22：60 秒・正しいキー 240・ミス 10・完了 8 問で、正確率 96.0%・KPM 240.0・完了 8 問を表示する。
- [ ] AC-23：30 秒・正しいキー 90・ミス 10 で、正確率 90.0%・KPM 180.0 を表示する。
- [ ] AC-24：無入力のまま終了すると、正しいキー・ミス・完了問題数は 0、正確率は 0.0%・KPM は 0.0 となり、不正な数値を表示しない。
- [ ] AC-25：正しいキー 1・ミス 2 の正確率を 33.3%、正しいキー 2・ミス 1 を 66.7% と表示する。
- [ ] AC-26：再挑戦では設定を維持し、集計値と問題の進捗を初期化してカウントダウンから始める。新たに抽選した結果が偶然前回と同じ問題でも正しい動作とする。
- [ ] AC-27：中止ボタン・Escape で設定画面へ戻り、途中結果を保存しない。設定値は維持する。IME 変換中の Escape は中止に使わない。
- [ ] AC-28：再読み込みすると初期設定に戻り、過去の結果や途中状態を復元しない。

参照：[ゲーム仕様](game-rules.md)、[画面仕様](screens.md)。

## 6. 表示・利用環境

- [ ] AC-29：キーボードだけで設定・開始・中止・再挑戦・設定変更を操作でき、フォーカス位置が見える。
- [ ] AC-30：プレイ開始時と次問への遷移時に入力できる。入力領域からフォーカスを外すと回答を数えず、選択し直すと回答を再開できる。
- [ ] AC-31：入力位置とミスが色だけに依存せず分かり、IME 案内・フォーカス案内・一時停止がないことを確認できる。
- [ ] AC-32：対象ブラウザーのリリース時点の安定版で、幅 1024 CSS px 以上なら問題・ガイド・操作が重ならない。狭い画面では利用環境の案内が出る。
- [ ] AC-33：初期資材の読み込み後、問題生成・判定・結果計算で通信せず、入力履歴を外部に送らない。Cookie・localStorage・IndexedDB にゲームの情報を残さない。
- [ ] AC-34：問題生成・判定データの不整合時に設定画面へ戻って案内を表示し、正常終了の成績を作らない。

参照：[要件定義](requirements.md)、[画面仕様](screens.md)、[構成・データ設計](architecture.md)。
