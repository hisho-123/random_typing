# ゲーム仕様

要件・採用理由は[要件定義](requirements.md)、入力判定の詳細は[ローマ字入力仕様](romanization.md)を参照する。

## 1. 設定

| 項目 | 選択値 | 初期値 |
| --- | --- | --- |
| 制限時間 | 30 / 60 / 120 秒 | 60 秒 |
| 1 問の平仮名数 | 5 / 8 / 12 文字 | 8 文字 |

設定は設定画面でのみ変更できる。再挑戦では直前の設定を引き継ぐ。
ページを再読み込みすると初期値に戻る。

## 2. 出題

- [ローマ字入力仕様](romanization.md)の対応表にある 71 文字を出題集合とする。
- 指定文字数になるまで、1 文字ずつ等しい確率 `1 / 71` で独立に抽選する。
- 同じ文字の連続や、前問と同じ問題の再出題を許容する。
- 単語・文章の辞書は使用せず、意味の有無による再抽選も行わない。
- 空白、区切り記号、漢字、片仮名は含めない。
- 出題時に平仮名から入力候補と表示用のローマ字ガイドを生成する。
- 1 問を完了したら、確認操作や待機時間を挟まず新しい問題を表示する。
- 次問へ進めたキーを、そのまま次問の先頭入力として扱わない。

例：5 文字設定なら `ぬせばとみ` のような文字列を生成する。例示した文字列を固定問題として使用するわけではない。

## 3. 状態と遷移

| 状態 | 内容 | 次の状態へ移る条件 |
| --- | --- | --- |
| 設定 `ready` | 設定を選び、操作方法を確認する | 開始で `countdown` |
| カウントダウン `countdown` | 3 → 2 → 1 を各 1 秒表示する | 合計 3 秒経過で `playing`、中止で `ready` |
| プレイ `playing` | 出題・入力判定・時間計測を行う | 時間切れで `finished`、中止で `ready` |
| 結果 `finished` | 確定した成績を表示する | 再挑戦で `countdown`、設定変更で `ready` |

- 連続した開始操作で、タイマーやゲームを複数開始しない。
- カウントダウン開始時に前回の進捗・成績を破棄し、新しいゲームを用意する。
- 最初の問題は `playing` への遷移時に表示し、その時点から制限時間を数える。
- カウントダウン中の回答キーは記録も持ち越しもしない。
- 中止は即時に行い、途中成績は保存せず、結果画面も表示しない。設定値は保持する。
- 時間切れで成績を一度だけ確定し、`finished` 以降は入力や遅れて届いた処理で変更しない。

## 4. 時間計測

- 開始時刻を `startedAt`、設定時間のミリ秒を `durationMs` とする。
- 単調増加する時計を使い、`deadline = startedAt + durationMs` とする。
- 内部残り時間は `max(0, deadline - now)` で求める。定期処理の実行回数を減算して時間を作らない。
- 画面では残りミリ秒を秒へ切り上げて表示する。終了時は 0 秒とする。
- キー入力を判定する直前にも時刻を確認し、`now >= deadline` なら入力を数えずゲームを終了する。
- 定期的な画面更新でも終了を確認し、無入力でも時間切れにする。
- タブ移動、ウィンドウの非アクティブ化、入力領域からのフォーカス移動で一時停止しない。
- バックグラウンドで描画が遅れた場合は、次の処理時に残り時間を再計算する。期限後に戻った場合は結果画面を表示する。
- 初版には一時停止・再開機能を設けない。

問題完了と時間切れが近接した場合も、入力判定直前の時刻で決める。期限前に受理した最後のキーなら、その問題を完了問題数に含める。

## 5. 入力と進捗

正誤・完了の判定と進捗の更新は、[ローマ字入力仕様の「判定方法」](romanization.md#3-判定方法)に従う。
判定対象外の入力と回答受付条件は、同仕様の[「キーイベントの扱い」](romanization.md#4-キーイベントの扱い)で定義する。

途中まで入力した問題の正しいキー数とミス数も成績に含めるが、完了問題数には含めない。

## 6. 成績

| 指標 | 定義 | 表示 |
| --- | --- | --- |
| 正しいキー数 `correctKeys` | 有効な接頭辞として受理したキー入力の合計 | 非負整数、単位「キー」 |
| ミス数 `missKeys` | 誤入力と判定したキー入力の合計 | 非負整数、単位「回」 |
| 正確率 `accuracy` | `correctKeys / (correctKeys + missKeys) × 100` | 小数第 1 位まで、単位 `%` |
| KPM `kpm` | `correctKeys / (durationSeconds / 60)` | 小数第 1 位まで、単位「キー/分」 |
| 完了問題数 `completedQuestions` | 最後まで正しく入力した問題の数 | 非負整数、単位「問」 |

- 正確率の分母が 0 の場合は `0.0%` とする。無入力時は、ほかの指標もそれぞれの表示形式で 0 を示す。
- 表示時に小数第 2 位を四捨五入し、内部値は表示用に丸めない。
- KPM は実際の結果画面への遷移時刻ではなく、設定した制限時間を分母に使う。
- 複数の正しい表記で入力キー数が異なる場合、実際に受理したキー数を数える。
- 1 回のキー入力は、正しいキー・ミス・対象外のいずれか一つだけに分類する。
- 独自の総合点、減点、ランキングは設けない。

計算例：60 秒で正しいキー 240、ミス 10、完了 8 問なら、正確率 `96.0%`、KPM `240.0`、完了問題数 `8 問` とする。
30 秒で正しいキー 90、ミス 10 なら、正確率 `90.0%`、KPM `180.0` とする。
