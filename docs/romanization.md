# ローマ字入力仕様

## 1. 対応する平仮名と表記

初期リリースで出題する全 71 文字を以下に定義する。
`/` は受け付ける表記の区切りであり、キーとして入力するものではない。
各欄の最初の表記を、初期表示用の推奨表記とする。

| 行 | あ段 | い段 | う段 | え段 | お段 |
| --- | --- | --- | --- | --- | --- |
| 母音 | あ `a` | い `i` | う `u` | え `e` | お `o` |
| か | か `ka` | き `ki` | く `ku` | け `ke` | こ `ko` |
| さ | さ `sa` | し `shi / si` | す `su` | せ `se` | そ `so` |
| た | た `ta` | ち `chi / ti` | つ `tsu / tu` | て `te` | と `to` |
| な | な `na` | に `ni` | ぬ `nu` | ね `ne` | の `no` |
| は | は `ha` | ひ `hi` | ふ `fu / hu` | へ `he` | ほ `ho` |
| ま | ま `ma` | み `mi` | む `mu` | め `me` | も `mo` |
| や | や `ya` | — | ゆ `yu` | — | よ `yo` |
| ら | ら `ra` | り `ri` | る `ru` | れ `re` | ろ `ro` |
| わ | わ `wa` | — | — | — | を `wo` |
| が | が `ga` | ぎ `gi` | ぐ `gu` | げ `ge` | ご `go` |
| ざ | ざ `za` | じ `ji / zi` | ず `zu` | ぜ `ze` | ぞ `zo` |
| だ | だ `da` | ぢ `di` | づ `du` | で `de` | ど `do` |
| ば | ば `ba` | び `bi` | ぶ `bu` | べ `be` | ぼ `bo` |
| ぱ | ぱ `pa` | ぴ `pi` | ぷ `pu` | ぺ `pe` | ぽ `po` |

残る 1 文字の「ん」は、次節の規則で受け付ける。
ここにない表記（例：`い = yi`、`う = wu`、`し = ci`）は初版の対象外とする。
`ぢ` は `di`、`づ` は `du` とし、`じ`・`ず` と表記を共有させない。

出題しない文字：`ぁぃぅぇぉゃゅょっゎゐゑゔ`、長音符、その他この表にない文字。

## 2. 「ん」の扱い

- 位置にかかわらず `nn` と `n'` を受け付ける。アポストロフィーは半角の `'` とする。
- 次の平仮名が「あ・い・う・え・お・や・ゆ・よ・ん」以外なら、単独の `n` も受け付ける。
- 問題末尾の「ん」は `nn` または `n'` で確定し、単独の `n` だけでは完了しない。
- 「んな」は `nna` と `nnna` の両方を受け付ける。連続する「ん」はそれぞれ `nn` または `n'` で入力し、「んん」は `nnnn` などで完了する。
- 初期ガイドでは常に `nn` を用いる。

例：

| 平仮名 | 有効な入力例 | 無効な入力例 |
| --- | --- | --- |
| んか | `nka`、`nnka`、`n'ka` | `nqa` |
| んあ | `nna`、`n'a` | `na` |
| んや | `nnya`、`n'ya` | `nya` |
| かん | `kann`、`kan'` | `kan` だけでの完了 |
| んな | `nna`、`nnna`、`n'na` | `na` |
| んん | `nnnn`、`nnn'`、`n'nn`、`n'n'` | `nnn` だけでの完了 |

連続する「ん」で単独の `n` を許すと、短い表記が長い表記の途中で完成してしまう。
1 問完了後に即座に次問へ進む仕様と両立させるため、次の文字も「ん」の場合は単独の `n` を許可しない。

## 3. 判定方法

1. 問題全体について、上記の表記と「ん」の文脈規則から有効な入力経路を定義する。
2. 受理済み入力に今回のキーを足した文字列が、いずれかの経路の接頭辞なら正しい入力とする。
3. 有効な接頭辞でなければミス数だけを増やし、受理済み入力と経路は変更しない。
4. いずれかの経路全体と一致したら、その問題を完了する。

最初のキーだけで表記を一つに固定しない。たとえば「し」の `s` の後は、`h` と `i` の両方を有効な次のキーとする。
問題全体の表記をすべて文字列に展開する必要はない。実装では経路を段階的に追跡し、文字数や表記候補数の増加に対応する。

### ガイドと入力位置

- 初期ガイドは各文字の推奨表記を連結したものとする。
- 入力後は、受理済み入力に一致する経路のうち、各文字の表記を対応表の記載順で優先した最初の経路をガイドに使う。「ん」は `nn` → `n'` → 文脈上許される `n` の順とする。
- ガイドは受理済み部分と未入力部分を分け、現在位置を示す。
- 平仮名の入力済み表示は、残っている全経路で確実に完了している先頭の文字までとする。
- 「ん」の `n` など、境界が未確定の入力は保留できる。受理したキー数は即座に増やすが、平仮名の確定表示を先走らせない。

例：「し」に `s` → `i` と入力した場合、初期ガイド `shi` は入力に合わせて `si` に変わり、2 キーで完了する。
「んか」に `n` と入力した時点では `nka`・`nnka`・`n'ka` の可能性を残し、続く `k`・`n`・`'` のいずれも正解とする。

## 4. キーイベントの扱い

| 入力 | 扱い |
| --- | --- |
| 半角英字 `a`〜`z` | 正誤判定の対象 |
| 半角英字 `A`〜`Z` | 小文字に変換して正誤判定する |
| 半角アポストロフィー `'` | 正誤判定の対象。「ん」の有効な経路以外ではミス |
| Backspace / Delete | 無視する。入力の巻き戻し・成績の取り消しは行わない |
| 数字、空白、その他の記号、カーソルキー | 回答としては無視する |
| Shift 単独などの修飾キー | 無視する |
| Ctrl / Meta / Alt を伴うキー | 回答としては無視し、ショートカットを妨げない |
| `event.repeat = true` のキーリピート | 無視する。長押しによる連続正解を防ぐ |
| IME 変換中、全角文字、貼り付け | 回答として受け付けず、ミスにも数えない |
| Escape | [画面仕様の「共通の操作・アクセシビリティ」](screens.md#5-共通の操作アクセシビリティ)で定める中止操作に使用する |
| Tab、ボタンへの Enter / Space | フォーカス移動・ボタン操作に使用する |

- 入力判定には文字を表すキー値を使い、キーボード上の物理位置だけで判定しない。
- 回答キーを受け付けるのは、プレイ中で入力領域にフォーカスがある場合だけとする。
- IME の変換開始を検出した場合は「IME をオフにして、半角英数で入力してください」と案内する。時間は停止しない。
- 回答文字はイベント単位で判定し、入力欄に確定した文字列を後から採点する方式にはしない。
- フォーカス移動やブラウザー標準の操作を必要以上に妨げない。
