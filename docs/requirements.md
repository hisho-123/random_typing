# 要件定義

## 1. 目的

ランダムな平仮名を読み、対応するローマ字を入力するタイピング練習用 Web アプリを提供する。
既知の単語や文章の暗記に頼らず、表示された文字に合わせてキーを入力する練習を想定する。

## 2. 要望と初期設計案

### ユーザーの要望

| ID | 要望 |
| --- | --- |
| REQ-01 | ブラウザーで利用できるタイピング練習アプリであること。寿司打を参考にする |
| REQ-02 | 意味を伴わないランダムな平仮名を出題すること |

### 初版で採用する設計上の仮定

以下はユーザーが指定した条件ではなく、このドラフトで提案する仕様である。
変更する場合は、対応する仕様と受け入れ基準も更新する。

| ID | 採用する案 | 理由 |
| --- | --- | --- |
| A-01 | PC と物理キーボードを主な利用環境とする | 初期リリースの入力環境を絞るため |
| A-02 | 平仮名を見てローマ字を直接入力する。かな入力・IME 変換は対象外 | キー単位で正誤と入力速度を判定するため |
| A-03 | 制限時間は 30・60・120 秒から選択し、初期値は 60 秒 | 短時間から練習できるようにするため |
| A-04 | 1 問の文字数は 5・8・12 文字から選択し、初期値は 8 文字 | 問題の長さを利用者が調整できるようにするため |
| A-05 | 出題は清音・濁音・半濁音の計 71 文字から行う | 基本的な平仮名を対象とし、小書き文字の組合せを初版から切り離すため |
| A-06 | 各文字を一様に抽選し、単語辞書による除外は行わない | 語彙の選出ではなく文字の無作為な組合せとして REQ-02 を具体化するため |
| A-07 | 会員登録、サーバー API、成績の永続保存は設けない | まず練習と結果確認までを完結させるため |
| A-08 | 正しく入力したキー数、ミス数、正確率、KPM、完了問題数を表示する | 入力速度と正確さをそれぞれ確認できるようにするため |

A-06 では、偶然実在する単語になる場合がある。「あらゆる有意味語を排除する」ことは初版では保証しない。
厳密な除外が必要になった場合は、対象辞書・判定範囲・抽選方法を別途定義する。

## 3. 利用の流れ

1. 制限時間と出題文字数を選ぶ。
2. 開始操作後、3 秒のカウントダウンを見る。
3. 平仮名の問題とローマ字ガイドを見ながら入力する。
4. 1 問を入力し終えたら、次の問題を続けて入力する。
5. 制限時間が終了すると成績を確認する。
6. 同じ設定で再挑戦するか、設定を変更する。

| ID | 要件 | 詳細の参照元 |

| FR-04 | 正しい入力だけを進捗に反映し、誤入力を記録する | [ローマ字入力仕様](romanization.md) |
| FR-05 | 残り時間と現在の入力位置を表示する | [画面仕様](screens.md) |

## 5. 非機能要件

| ID | 要件 |
| --- | --- |
| NFR-01 | 画面の説明・操作ラベルは日本語とする |
| NFR-02 | 対象ブラウザーはデスクトップ版 Chrome・Edge・Firefox・Safari とし、リリース時点の各安定版で受け入れ確認を行う |
| NFR-03 | 設定、開始、再挑戦、中止をキーボードだけでも操作でき、フォーカス位置が分かる |
| NFR-04 | 入力済み・入力待ち・ミスを色だけで区別せず、位置・記号・数値でも示す |
| NFR-05 | 初期表示に必要な資材を読み込んだ後は、出題・入力判定・成績計算で通信しない |
| NFR-06 | 判定をキー入力イベント内で行い、次の描画で進捗を反映する。問題生成や通信待ちで入力受付を止めない |
| NFR-07 | ブラウザー内のメモリーだけで状態を保持し、個人情報や入力履歴をサーバーへ送らない。初版には外部解析・広告を含めない |
| NFR-08 | 幅 1024 CSS px 以上で主要な操作・問題が重ならず表示される。狭い画面では対象環境の案内を表示する |

ブラウザー対応は実装後に検証する目標であり、この仕様作成時点で動作確認済みという意味ではない。

## 6. 初期リリースの対象外

- スマートフォンのソフトウェアキーボードへの対応。
- 日本語 IME・かな入力による回答。
- 拗音、促音、小書き文字、長音符、数字、記号の出題。
- 会員登録、ログイン、ランキング、成績履歴、設定の永続保存。
- 難易度に応じた抽選確率の調整、苦手文字の学習、意味のある単語の出題。
- 寿司の画像、価格・損得の計算、音声・効果音。

## 7. 実装着手時に確認する事項

このドラフトの挙動は A-01〜A-08 を既定として記述しているが、承認済みの要件とは区別する。

| 項目 | 現時点の扱い |
| --- | --- |
| 時間・文字数・文字種・入力方式・保存範囲 | A-01〜A-08 の妥当性を確認する |
| 正式なサービス名・画面の意匠 | 未決定。`Random Typing` は仮の表示名 |
| フロントエンドの言語・フレームワーク | 未決定。仕様は特定技術に依存させない |
| 公開 URL・ホスティング・配布方法 | 未決定 |
| 仕様リポジトリ名 | 現行は `random_typing`。命名ルールに合わせる場合は `random_typing_docs` |

## 8. 関連リポジトリへの影響

参照可能なローカル範囲に `random_typing_docs` や同サービスの実装リポジトリは存在しないため、既存実装との比較は行えない。
初期リリースはフロントエンドのみで成立する設計とする。
今後 `random_typing_frontend` を作成する場合は本仕様を参照し、API や永続化を追加する場合はデータ設計と非機能要件も更新する。
