# 画面仕様

画面は設定・プレイ・結果の 3 種類とし、カウントダウンはプレイ画面内で表示する。
URL の分割や画面の装飾は実装時に決める。

## 1. 設定画面

| 要素 | 表示・動作 |
| --- | --- |
| タイトル | `Random Typing`（仮称） |
| 説明 | 「ランダムな平仮名をローマ字で入力して練習します」 |
| 制限時間 | ラベル付きの選択肢。選択値・初期値は[ゲーム仕様の「設定」](game-rules.md#1-設定)に従う |
| 出題文字数 | ラベル付きの選択肢。選択値・初期値は[ゲーム仕様の「設定」](game-rules.md#1-設定)に従う |
| 操作説明 | 「IME をオフにして、半角英数で入力してください」「ミスしても入力位置は戻りません」「中止は Escape キーでも操作できます」 |
| 開始ボタン | 「練習を開始」。選択した設定でカウントダウンを開始する |
| 利用環境の案内 | [要件定義の NFR-08](requirements.md#5-非機能要件)で定める幅に満たない場合、「PC と物理キーボードでの利用を推奨します」と表示する |

選択肢はクリックとキーボードのどちらでも操作できる。
設定画面へ戻った際は直前の設定値を維持し、開始ボタンにフォーカスを置く。
初回表示時に利用者の操作なくゲームを開始しない。

## 2. カウントダウン

表示順序・時間・回答入力の扱いは、[ゲーム仕様の「状態と遷移」](game-rules.md#3-状態と遷移)に従う。

- 残りのカウントを画面中央に表示する。
- 選択した制限時間と文字数を確認できる。
- 「中止」ボタンを表示する。

## 3. プレイ画面

| 要素 | 表示・動作 |
| --- | --- |
| 残り時間 | 秒単位で表示。計算方法は[ゲーム仕様](game-rules.md)に従う |
| 問題 | 現在の平仮名列を大きく表示する |
| ローマ字ガイド | 現在有効な表記を表示し、受理済み部分と未入力部分を区別する |
| 入力位置 | 下線・カーソルなど、色以外の手掛かりでも示す |
| 途中成績 | 正しいキー数、ミス数、完了問題数を表示する |
| ミス表示 | 誤入力時に `×` と「ミス」を約 200 ms 表示する。連続ミスでは最後のミスから表示時間を取り直す |
| 入力領域 | フォーカス可能な回答受付領域。ラベルを設け、ブラウザーによる綴り修正・予測入力に依存しない |
| 入力状態の案内 | IME 変換を検出した場合の半角英数案内、フォーカスを失った場合の「入力領域を選択して続けてください」 |
| 中止ボタン | 途中結果を破棄して設定画面へ戻る |

- プレイ開始時に入力領域へフォーカスを置く。
- 1 問完了後も入力領域のフォーカスを維持し、続けて入力できる。
- 入力中の平仮名・ローマ字ガイドが、残り時間やボタンと重ならないよう配置する。
- ミスのたびに問題全体を移動させるなど、入力位置を見失う演出は行わない。
- フォーカスを失った後は、入力領域を選択すると回答を再開できる。回答受付条件は[ローマ字入力仕様](romanization.md#4-キーイベントの扱い)、時間の進行は[ゲーム仕様](game-rules.md#4-時間計測)に従う。
- 誤入力時の進捗表示は[ローマ字入力仕様の「判定方法」](romanization.md#3-判定方法)に従う。

## 4. 結果画面

| 要素 | 表示・動作 |
| --- | --- |
| 見出し | 「練習結果」 |
| 今回の設定 | 制限時間と出題文字数 |
| 成績 | [ゲーム仕様の「成績」](game-rules.md#6-成績)で定義する全指標 |
| KPM の説明 | 「1 分あたりの正しいキー入力数」 |
| 再挑戦ボタン | 「同じ設定でもう一度」。同じ設定・新しい問題でカウントダウンから開始する |
| 設定変更ボタン | 「設定を変更」。直前の設定を保持して設定画面へ戻る |

- 成績の単位・丸め方・無入力時の値は[ゲーム仕様の「成績」](game-rules.md#6-成績)に従う。
- 結果表示時に見出しへフォーカスを移し、結果画面へ移ったことが支援技術でも分かるようにする。
- 結果を入力キーだけで閉じない。ボタン操作によって次の練習へ進む。

## 5. 共通の操作・アクセシビリティ

- すべてのボタンと選択肢に、表示内容と対応するラベルを設ける。
- Tab でフォーカス移動し、Enter / Space で標準のボタン操作ができる。
- フォーカスの輪郭を視認できるようにする。
- 入力済み部分は色に加えて文字の強調や下線でも区別する。
- 画面遷移やゲーム終了は支援技術に通知する。残り時間やキーごとの変化をすべて読み上げさせない。
- 一時停止がないこと、フォーカスを外しても時間が進むことをプレイ画面で確認できるようにする。
- カウントダウン中・プレイ中の Escape は、アプリの領域にフォーカスがある場合に中止として扱う。ただし IME 変換中は IME の操作を優先する。
