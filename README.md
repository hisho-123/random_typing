# Random Typing 仕様管理

寿司打を参考にした、タイピング練習用 Web アプリの仕様を管理するリポジトリです。
意味のある単語や文章を問題として選ぶのではなく、ランダムに組み合わせた平仮名を出題します。

## 仕様書

| 文書 | 内容 |
| --- | --- |
| [要件定義](docs/requirements.md) | アプリの目的、初期リリースの範囲、要件と設計上の仮定 |
| [ゲーム仕様](docs/game-rules.md) | 出題、制限時間、状態遷移、成績の計算 |
| [ローマ字入力仕様](docs/romanization.md) | 対応する文字、入力表記、正誤判定 |
| [画面仕様](docs/screens.md) | 設定・プレイ・結果画面の表示と操作 |
| [構成・データ設計](docs/architecture.md) | 実装の責務、データ、関連リポジトリとの関係 |
| [受け入れ基準](docs/acceptance-criteria.md) | 実装完了を判断する確認項目 |

最初に要件定義を読み、実装時にはゲーム仕様・ローマ字入力仕様・画面仕様を参照してください。
検証には受け入れ基準を使用します。

## 現在の状態

- 仕様の状態：初版ドラフト。
- ユーザーの要望として確定しているのは「タイピング練習用 Web アプリ」と「ランダムな平仮名の出題」です。
- 制限時間、文字種、ローマ字入力、成績表示などは、実装可能な形にするために置いた初期設計案です。
- 寿司打は着想の参考です。名称、画像、音源、画面デザインの流用は仕様に含みません。
- このリポジトリにはアプリの実装を置かず、仕様・設計・受け入れ基準を管理します。

## リポジトリの関係

サービスの識別子は、現在のリポジトリ名に合わせて `random_typing` とします。
共通命名ルールに従う場合の構成は次のとおりです。

| リポジトリ | 役割 | 現状 |
| --- | --- | --- |
| `random_typing_docs` | 仕様・設計の参照元 | 現在は本リポジトリ `random_typing` が担当 |
| `random_typing_frontend` | ブラウザーで動作するアプリ | ローカルの参照可能な範囲には存在しない |
| `random_typing_backend` | API・サーバー処理 | 初期リリースでは不要 |
| `random_typing_infrastructure` | 配信環境・環境管理 | 配信先の決定後に必要性を判断 |

この仕様作成では、既存リポジトリの改名や関連リポジトリの作成は行っていません。
関連リポジトリができた際は、実装側の README から本仕様への参照を設けます。

## 仕様の更新

1. 変更する要件と、影響する入力・画面・成績計算を確認する。
2. 関連する仕様と受け入れ基準を同じ変更で更新する。
3. 関連リポジトリの実装を確認し、必要な実装変更と未対応事項を記録する。

未決定事項と、今回採用した仮定は[要件定義](docs/requirements.md)で管理します。
